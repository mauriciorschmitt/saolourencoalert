Uso interno da equipe do projeto

Observação de campo

Preencha aqui, na margem da represa. A localização vem do aparelho e as fotos você anexa no passo seguinte.

Quando
Onde

Use sempre o mesmo nome para o mesmo lugar — é o que permite comparar o local ao longo do tempo.

A localização é lida do GPS do aparelho e não sai daqui até você enviar.

O que você viu

Registrar ausente é tão útil quanto confirmar um alerta: sem observações de normalidade não há como medir falso positivo.

Complementos

O envio abre uma página do GitHub já preenchida. Lá você:
  1. anexa as fotos, arrastando ou pelo botão de imagem;
  2. confere os dados;
  3. toca em Create.
A observação entra no sistema automaticamente em alguns minutos, e a validação é recalculada no monitoramento seguinte.
